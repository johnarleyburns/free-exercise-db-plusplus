# v0.3 patch notes

This pass targets conventional low-confidence exercises only.

Changes:
- adds explicit triceps-biased horizontal press and dip patterns;
- broadens vertical press recognition (Arnold, seated/standing dumbbell, kettlebell, Bradford, behind-neck);
- recognizes floor/board/pin/chain/JM/close-grip presses;
- recognizes pullups/chins/V-bar variants;
- recognizes chest- and triceps-biased dips;
- recognizes rack pulls;
- recognizes glute-ham raises and common hip-extension variants;
- recognizes Pallof press, side bridge/jackknife, and several obvious trunk-flexion exercises;
- recognizes monster walk and backward drag;
- broadens fly/reverse-fly names;
- fixes reverse-wrist-curl rule ordering;
- adds reviewed high-confidence overrides for Pullups, chest/triceps dips, and GHR variants.

Deliberately not addressed yet:
- cleans, snatches, jerks and derivatives;
- Atlas stones, tire flips, log lifts and other complex strongman movements;
- complex kettlebell ballistic combinations;
- unusual integrated movements where direct-set accounting is debatable.

## Schema 0.2.0 classification update

This v0.3 patch also adds normalized exercise classification while preserving upstream category/equipment under `source`.

## Workout interchange schema

v0.3 now includes a separate set-level `workout.schema.json`, an example session, and mapping placeholders. Exercise definitions and workout observations remain deliberately separate.
