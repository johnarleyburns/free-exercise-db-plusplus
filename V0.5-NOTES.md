# v0.5 evidence/provenance architecture

Free Exercise DB++ v0.5 separates:

1. muscle-role classification (`direct`, `indirect`, `stabilizers`);
2. evidence provenance for the movement-pattern mapping;
3. analytical set-credit models.

## Exercise schema 0.3.0

`metadata.setCredits` is removed.

New metadata fields:
- `analysisModelRegistry`
- `defaultAnalysisModelId`
- `evidenceRegistry`

Each annotation now has `evidenceRefs`, for example:

```json
"evidenceRefs": ["pattern:horizontal_press"]
```

## Evidence registry

`evidence/pattern-evidence.json` contains every canonical pattern and explicitly labels it:
- supported
- indirect_support
- complex_supported
- provisional

No citation is treated as an explicit provisional state, not silent validation.

## Analysis models

`analysis-models.json` contains named models rather than embedding weights into anatomy.

Default:
`fractional_sets_1_0_0` = direct 1.0, indirect 0.5, stabilizer 0.0.

This is a published volume-counting approach used in a recent meta-regression (PMID 41343037), but DB++ explicitly describes it as an analytical convention rather than a biological constant.

Also included:
- `direct_only_1_0_0`
- `total_sets_1_1_0`

Consumers can choose a model without changing the exercise database.
