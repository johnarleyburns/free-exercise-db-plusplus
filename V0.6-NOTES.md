# v0.6 evidence completion pass 1

v0.6 leaves the DB++ consumer contract unchanged: `free-exercise-db-plusplus.json`
remains the only data file an application needs.

New targeted literature support was added for:
- vertical press
- shoulder abduction / lateral raise
- shoulder flexion / front raise
- reverse fly
- shrug
- elbow flexion
- brachioradialis-biased elbow flexion
- elbow extension
- knee extension

This pass deliberately does **not** promote a pattern merely because its anatomy
seems obvious. `supported` means DB++ has attached targeted empirical literature
to the mapping.

Remaining provisional canonical patterns after this source-level pass: 27.

`generate_evidence_audit.py` creates `EVIDENCE-AUDIT.md`, sorted by actual
exercise usage, so subsequent evidence work attacks the highest-impact remaining
patterns first. This audit is a build/reviewer artifact, not a runtime dependency.
