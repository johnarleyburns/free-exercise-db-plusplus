# v0.6.1 — complete evidence coverage for all used patterns

Every canonical pattern actually used by the current 873-exercise corpus now has non-provisional evidence status.

Statuses remain intentionally nuanced:
- supported: targeted empirical evidence for that movement family
- complex_supported: direct evidence for a multi-phase event, with DB++ roles as a whole-event abstraction
- indirect_support: exact exercise evidence was not located; closely related mechanics support the mapping
- provisional: permitted only for zero-use taxonomy patterns

The build now fails if any used pattern is provisional.

Zero-use taxonomy patterns intentionally left provisional:
- dorsiflexion
- neck_extension
- neck_flexion
- wrist_extension
- wrist_flexion

The runtime contract remains unchanged: consumers need only free-exercise-db-plusplus.json.
