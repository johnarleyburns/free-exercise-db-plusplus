# ADR 0019: Explainable CoachDecision artifacts

Status: accepted (v1.7)

Every CoachDecision contains before/after prescription values, stable reason
codes, machine-readable set evidence, policy identity, and provenance. A
decision is advisory domain output: it does not create a plan revision, activate
a plan, replace an exercise, or express intent, motivation, fatigue, recovery,
injury, or medical advice.
