The prior v1.14.0 gap was a test and integration gap: R parity was claimed
without a first-class application contract, and the release did not provide
an equivalent full-envelope fixture harness for application orchestration.
This pass adds the harness and executes every application fixture family
end-to-end in each language. All discovered representation differences were
fixed at the language boundary; one complete adversarial pass found zero
unresolved high- or medium-severity gaps.
