# v0.5.1 single-JSON simplification

Mid-course correction:

- Free Exercise DB++ remains a single self-contained JSON artifact.
- The project uses one set-credit model only:
  - direct = 1.0
  - indirect = 0.5
  - stabilizer = 0.0
- Evidence/provenance is embedded directly in `free-exercise-db-plusplus.json`.
- Separate JSON Schema files remain allowed for validation.

The generated JSON metadata now contains:
- `setCredits`
- `setCreditEvidence`
- `evidence.references`
- `evidence.patterns`

Applications only need `free-exercise-db-plusplus.json` to process the database.
They do not need to fetch any helper registries.

The 1.0 / 0.5 / 0.0 model is treated as the DB++ supported model, with the
published fractional-set meta-regression reference embedded as provenance.
