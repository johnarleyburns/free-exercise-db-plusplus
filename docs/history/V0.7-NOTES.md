# v0.7 — evidence-driven rule promotion

Recognized movement-pattern mappings now derive confidence from the embedded
evidence status rather than from a blanket "compound = medium" rule.

Policy:
- supported -> high confidence
- complex_supported -> medium confidence
- indirect_support -> medium confidence
- provisional -> medium confidence

Supported patterns receive no review reason. Complex and indirectly supported
patterns remain explicitly reviewable.

The workflow now verifies this evidence/confidence contract and publishes
RULE-AUDIT.md with per-pattern usage and high/medium counts.

The consumer contract is unchanged: free-exercise-db-plusplus.json remains the
only runtime data file required.
