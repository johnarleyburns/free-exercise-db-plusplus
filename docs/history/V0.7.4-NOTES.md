# v0.7.4 — fallback cleanup

This pass reduces plain upstream primary/secondary fallbacks using exact-name,
evidence-backed mappings.

New supported canonical patterns:
- forearm_pronation
- forearm_supination
- grip
- neck_lateral_flexion

Existing neck_flexion and neck_extension evidence is upgraded to supported.

Exact-name mappings added for:
- Power Partials / deltoid raises -> shoulder_abduction
- front/overhead raise variants -> shoulder_flexion
- Reverse Machine Flyes -> reverse_fly
- One-Legged Cable Kickback / Leg Lift -> hip_extension
- Dumbbell Lying Pronation/Supination -> forearm rotation
- Plate Pinch / Plate Hand Squeeze / Wrist Roller / Wrist Rotations -> grip
- neck resistance exercises -> neck flexion/extension/lateral flexion

The combined Front And Back isometric neck exercise uses an explicit two-pattern
override.

Still-ambiguous exercises such as Car Drivers, Crucifix, and Downward Facing
Balance remain fallback-medium rather than being forced into a pattern.

Adds FALLBACK-AUDIT.md to make that residual set explicit.
