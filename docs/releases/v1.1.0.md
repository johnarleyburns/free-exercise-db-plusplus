# Free Exercise DB++ v1.1.0

## Workout PLAN / ACTUAL / TARGET analysis stabilization

v1.1.0 formally releases the completed semantic-hardening work around workout prescriptions, performed sessions, volume targets, and deterministic analysis.

Highlights include PLAN and ACTUAL interchange, TARGET profiles, direct/indirect/stabilizer/effective-set coverage, arbitrary-cycle and seven-day views, ranged prescriptions, periodized phases, PLAN-vs-PLAN comparison, exposure frequency, PLAN-vs-ACTUAL matching, explicit substitutions, unplanned work, adherence dimensions, TARGET gap analysis, deterministic research CSV output, and provenance metadata.

Analysis uses dbpp-default-volume-v1 and reads authoritative set credits from the analyzed database. The shipped database declares direct 1.0, indirect 0.5, and stabilizer 0.0. These are accounting credits, not physiological equivalence or a universal stimulus score.

The v1 exercise-definition contract remains compatible. Existing ACTUAL documents remain supported, and PLAN, TARGET, and analysis contracts retain their independent schema versions. No migration is required for the core database or standalone ACTUAL records.

The Python package exposes Database, Plan, VolumeTarget, analyze_plan, compare_to_targets, compare_plan_actual, and compare_plans. Swift, Kotlin, and R package tests remain part of the release gate.

Known limitations are intentional: external Garmin FIT, FHIR, HealthKit, Health Connect, and IEEE/Open mHealth exporters; taxonomy/fine-anatomy expansion; exercise-family work; and additional analysis metrics are deferred.
