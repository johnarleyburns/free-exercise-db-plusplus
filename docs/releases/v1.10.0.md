# Free Exercise DB++ v1.10.0

v1.10 adds the Python reference implementation of portable WorkoutIntent
resolution. It introduces schema `workout-intent` 0.1.0, explicit versioned
goal and environment policies, deterministic resolution provenance, CLI
commands, and cross-language parity fixtures.

`exercisesPerSession` is now a first-class TrainingProfile availability
constraint: evaluator minimum/maximum failures are hard, and the generator
honours the same limit while constructing a PLAN. Existing PLAN, ACTUAL,
TARGET, TrainingProfile, generation, TrainingState, and adaptive-coaching
contracts remain additive and compatible.

No natural-language parser, remote service, or model SDK is included. Python
is the full v1.10 reference; Swift, Kotlin, and R remain partial as documented
in the language capability matrix.
