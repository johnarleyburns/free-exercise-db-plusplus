# Free Exercise DB++ v1.11.0

Released: 2026-08-27

v1.11 completes the Python reference audit and full native Swift engine parity
without adding an LLM or network dependency. Swift covers structured
WorkoutIntent resolution, TARGET/profile semantics, plan analysis and
evaluation, history and adherence-rich TrainingState, progression,
deterministic production generation, CoachDecision, and adaptive coaching.
Python-authored fixtures, stable provenance, resource packaging, and an
external Swift consumer cover the released surface.

Kotlin/JVM remains at its existing partial capability boundary and its full
engine port is scheduled for v1.13. R remains at its existing partial research
boundary and its full engine port is scheduled for v1.14. v1.12 is Swift SPM
packaging and app-readiness polish, not unfinished core engine work. Apple
Foundation Models integration remains outside this repository.
