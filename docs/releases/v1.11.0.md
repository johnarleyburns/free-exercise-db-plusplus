# Free Exercise DB++ v1.11.0

Released: 2026-08-26

v1.11 adds the cross-language WorkoutIntent boundary without adding an LLM or
network dependency. Swift, Kotlin/JVM, and R now expose native structured
WorkoutIntent models, validation, and resolution APIs using the frozen Python
v1.10.1 semantics for core status/policy behavior. Stable result fields,
`defaultsApplied`, `explicitOverrides`, policy identities, and Monday-based
weekday semantics are documented and covered by shared fixtures.

The native bindings are intentionally honest about remaining capability gaps:
full adherence-rich TrainingState analysis and optimizer-equivalent native
intent-to-plan generation are deferred to v1.12. The v1.11 history feature is
a tested bounded 28-day projection, and native draft generation is deterministic
constraint-aware construction, not an optimizer. Apple Foundation Models
integration remains outside this repository.
