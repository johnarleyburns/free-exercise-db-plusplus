# Free Exercise DB++ v1.11.1

Release preparation for the v1.11 parity correction.

This patch release preserves the v1.11.0 public schemas and the immutable
`v1.11.0` tag. It corrects native Swift parity for history/state, progression,
generation, structured intent, and adaptive coaching. It also publishes the
Python-authored cross-language matrix, exact external Swift consumer checks,
and isolated installed-wheel acceptance.

Artifact versions retain their independent meanings: the project release is
`1.11.1`, the database `schemaVersion` is `0.3.0`, the database
`converterVersion` is `0.8.0`, and the relationship artifact schema remains
`0.1.0`. The relationship artifact's `metadata.projectRelease` remains
`1.5.1` because it identifies the release that introduced that independently
versioned artifact, not the current project release.
