# Free Exercise DB++ v1.12.0

Free Exercise DB++ v1.12.0 makes the completed Swift engine a production-ready
Swift Package Manager dependency for Apple applications and other Swift hosts
with Foundation. It does not introduce a new training algorithm milestone.

Highlights:

- one `TrainingEngine` facade with typed intent, plan, actual-workout, target,
  profile, history, state, evaluation, progression, and adaptation workflows;
- bundled offline resources through `TrainingEngine.bundled()` with no manual
  filesystem lookup;
- stable Codable contracts, deterministic results, and immutable concurrency-safe
  value types where applicable;
- machine-readable validation, clarification, unsatisfiable-plan, and coaching
  outcomes rather than prose-only error contracts;
- external Swift Package consumer coverage for first-time and history-aware apps;
- no Python runtime, subprocess, network service, LLM, UIKit, SwiftUI, or AppKit
  dependency in the semantic package;
- an explicit application boundary: the host app may use Apple Foundation Models
  or another parser to produce `WorkoutIntent`, while DB++ resolves and plans it.

The Python reference semantics and Swift v1.11 parity remain the baseline. Kotlin
is deferred to v1.13, and the full R engine/research port is deferred to v1.14.

See [the stable Swift API guide](../SWIFT-API.md) and the [Swift package README](../../packages/swift/README.md).
