# Free Exercise DB++ v1.13.0

Released 2026-08-28.

v1.13.0 completes the native Kotlin/JVM engine port. Android and plain JVM
applications can run the offline workflow:

```text
WorkoutIntent → resolveIntent → generatePlan → evaluatePlan
ACTUAL history → deriveTrainingState → progression → adaptPlan
```

The package bundles canonical database and relationship resources, uses typed
Kotlin models with kotlinx.serialization, preserves deterministic
cross-language semantics, and has no Android SDK, Python, subprocess, network,
or LLM dependency in its semantic core.

Validation includes shared Python-authored intent, evaluation, history,
progression, generation, and adaptation fixtures; an external Gradle/JVM
consumer; resource integrity; serialization round trips; and the repository
workflow. The R full research/analysis engine remains v1.14 work.
