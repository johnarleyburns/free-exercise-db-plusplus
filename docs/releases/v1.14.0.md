# v1.14.0 — R research engine

v1.14.0 adds the native R research/statistical interface for the released DB++
training semantics. It includes bundled-resource loading, PLAN/TARGET
evaluation, WorkoutIntent resolution, TrainingHistory and TrainingState,
progression, deterministic generation, adaptive coaching, serialization, and
base-R data-frame research views.

The R package remains dependency-light (`jsonlite` only), offline, deterministic,
and independent of Python, reticulate, Java, tidyverse, and LLM services.
