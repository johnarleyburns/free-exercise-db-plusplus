# v1.14.1 — R parity corrective patch

v1.14.1 is a corrective patch for the native R research engine. It adds
end-to-end Python-authored canonical parity checks for intent, evaluation,
history/TrainingState, progression, generation, and adaptation, and fixes the
remaining generation result and deterministic ordering differences identified
by the v1.14 audit.

The R package remains dependency-light (`jsonlite` only), offline, deterministic,
and independent of Python, reticulate, Java, tidyverse, and LLM services.
