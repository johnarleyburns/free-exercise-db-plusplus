# v1.15.0 — application integration contract

v1.15.0 makes the deterministic DB++ engine directly consumable by application
developers and autonomous coding agents. It adds the versioned `0.1.0`
`TrainingRequest` and `TrainingResult` schemas, explicit operation dispatch,
typed Swift and Kotlin facades, Python and R facades, bundled schema resources,
canonical application fixtures, four external consumers, and full
Python/Swift/Kotlin/R application-contract parity checks.

The contract keeps the host boundary explicit: DB++ resolves structured intent,
generates and evaluates plans, derives state, suggests progression, and proposes
adaptations. Host applications own natural-language parsing, persistence,
accounts, authorization, UI, approval, activation, and any LLM integration.
DB++ does not activate proposed revisions and does not introduce a network,
LLM, randomness, or implicit current-time dependency.

This release changes integration ergonomics only. Existing training semantics,
policy defaults, and lower-level domain APIs remain unchanged.
