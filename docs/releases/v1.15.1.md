# v1.15.1 — runnable external consumers

v1.15.1 is a documentation and external-consumer hardening patch over the
v1.15.0 application integration contract. It adds a complete persisted
PLAN/ACTUAL history workflow to the Swift external SPM example and mirrors the
same state, progression, and explicit adaptation flow in Kotlin/JVM, Python,
and R.

The Swift getting-started guide now contains real public Codable persistence
calls and links directly to the compiling example source. CI executes the
Swift and Kotlin examples, including adaptation, while the installed Python
and R consumer checks continue to run. DB++ only proposes revisions; host
applications remain responsible for review, persistence, approval, and
activation.

No training methodology, policy defaults, application contract, or semantic
engine behavior changed in this patch.
