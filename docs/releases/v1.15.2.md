# Free Exercise DB++ v1.15.2

This release adds an evidence-backed endurance goal policy and completes goal
policy provenance across all supported language engines.

- `endurance` now resolves to `general-endurance-v1` with conservative
  15--18--20 repetition, RIR 2, and chest/lats/quadriceps/hamstrings coverage
  defaults.
- Hypertrophy, strength, and endurance policies each declare their evidence
  status, interpretation, and registry references.
- The generated database embeds `repetition_continuum_2021` and
  `rir_rpe_scale_2016`; `converterVersion` is 0.8.1.
- Python, Swift, Kotlin, and R resolvers consume the shared policy catalog and
  pass the endurance cross-language parity fixture.
- The v1.0 exercise-data contract, `schemaVersion`, exercise IDs, muscle
  ontology, set credits, and existing policy numbers are unchanged.

The endurance defaults are conservative model defaults, not an optimal
prescription. Consumers can override target fields explicitly per request.
