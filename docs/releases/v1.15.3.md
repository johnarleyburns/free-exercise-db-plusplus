# Free Exercise DB++ v1.15.3

This contract-hardening patch follows v1.15.2. It does not introduce a new
goal or change the endurance policy; `general-endurance-v1` remains the
v1.15.2 conservative 15/18/20-repetition, RIR 2 model with its existing
coverage and evidence provenance.

- WorkoutIntent schema identity: `0.1.0` → `0.2.0` because the released goal
  vocabulary was expanded.
- TrainingProfile schema identity: `0.1.0` → `0.2.0` for the same reason.
- Runtime consumers retain the established compatibility behavior for
  historical `0.1.0` WorkoutIntent and TrainingProfile documents.
- The endurance fixture now covers complete resolution → generation →
  evaluation output, not only intent resolution.
- Python, Swift, Kotlin/JVM, and R execute the generation fixture and match the
  canonical Python result, including attached/standalone evaluation.
- The immutable upstream release snapshot remains pinned.
- No LLM/runtime/network dependency is added to DB++ engines.
