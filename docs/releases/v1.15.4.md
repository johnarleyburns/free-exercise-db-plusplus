# Free Exercise DB++ v1.15.4

This additive code-only patch exposes released goal-policy documents directly
to Swift consumers without changing intent resolution or engine output.

- Add the public package function `goalPolicy(_:)` and matching
  `TrainingEngine.goalPolicy(_:)` method.
- Return the immutable bundled goal-policy document for a known identifier and
  `nil` for an unknown identifier.
- Cover all three shipped goal policies and the `general-endurance-v1`
  15/18/20-repetition, RIR 2 defaults in Swift unit tests.
- Exercise data, intent policies, evidence, shared fixtures, and resolver
  behavior are unchanged.
- Database `schemaVersion` remains `0.3.0`; `converterVersion` remains `0.8.1`.
