# Free Exercise DB++ v1.16.0

Released 2026-09-05.

This release expands the catalog from 873 upstream records to 927 total
canonical records. The 54 new DB++-owned records cover real-world cable,
functional-trainer, selectorized, and plate-loaded movements found in current
commercial equipment catalogs.

Notable additions include `Cable_Push_Pull`, standing one-arm and bent-over
cable rows, machine high/low/seated rows, machine rotary torso, glute drive,
belt squat, V-squat, tibialis dorsiflexion, assisted dip/chin-up, and the
remaining catalog-derived variations documented in
[CATALOG-EXPANSION.md](../CATALOG-EXPANSION.md).

The upstream 873-record snapshot remains preserved. New records are original
vendor-neutral DB++ records with no copied vendor instructions or imagery.
