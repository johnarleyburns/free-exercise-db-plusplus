# Free Exercise DB++ v1.17.0

Released 2026-09-28.

This release adds full DB++ health-data import/export round trips for Garmin
FIT, Apple HealthKit, and Android Health Connect. Each target receives a native
projection plus an exact canonical DB++ ACTUAL sidecar, preserving every
DB++-supported health field across export and import.

Highlights:

- Garmin FIT binary encoding and decoding through Garmin’s official SDK
  boundaries, including FIT Developer Data fields.
- A native conditional Swift HealthKit adapter using `HKWorkoutBuilder` and
  HealthKit metadata.
- A portable C sidecar ABI for Garmin-C-SDK, Objective-C/HealthKit, and
  Android/JNI host integrations.
- Python, Kotlin/JVM, and R health-data envelopes and projections.
- Strict import behavior that rejects native-only records when a complete DB++
  reconstruction is impossible.

See [the health-data adapter guide](../interop/HEALTH-DATA-ADAPTERS.md) and
[the import/export contract](../interop/IMPORT-EXPORT.md).
