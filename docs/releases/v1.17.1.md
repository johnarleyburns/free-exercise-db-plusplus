# Free Exercise DB++ v1.17.1

This patch release keeps the v1.17.0 health-data adapter API and wire format
unchanged while restoring Swift 6/Xcode 26.6 source compatibility.

- Make every HealthKit adapter continuation's result type explicit so the
  Swift package builds under Swift 6.
- Mark the HealthKit adapter as macOS 13+ because its HealthKit types are not
  available on macOS 12.
- Rename the local HealthKit export end date so it does not shadow the helper
  method named `end`.

The Swift package test suite passes with 48 tests and no failures.
