# Free Exercise DB++ v1.18.0 release candidate

Prepared 2026-10-01; do not publish until native-language review is complete.

This release adds the multilingual exercise-name data model and locale-aware
lookup/search support while preserving stable English exercise IDs for mobile
apps and research datasets.

Supported locale tags:

- `en`, `es`, `de`
- `zh-Hans`, `zh-Hant`, `pt-BR`, `fr`, `ja`, `ko`, `hi`
- `ar`, `he`, `ru`, `nl`, `it`

The generated database embeds a 927-record catalog for every non-English
locale. Each entry carries source references and an explicit review status.
One Spanish entry is native-source reviewed; other localized candidates are
marked provisional, and names that remain English are marked untranslated.
This status distinction is intentional: the release provides usable locale
infrastructure and candidate coverage without presenting machine-generated or
unreviewed names as authoritative native terminology.

The pre-release audit in [`reports/LOCALIZATION-AUDIT.md`](../../reports/LOCALIZATION-AUDIT.md)
found zero automated residual-English, malformed-composition, or untranslated
fallback flags in all 14 non-English catalogs. Every catalog contains 927
explicit entries; one Spanish entry is native-source reviewed and the
remaining entries are provisional candidates or explicitly accepted
international exercise terms. Native review is still required before these
names can be called authoritative. Therefore this document is a release
candidate record, not authorization to cut the v1.18.0 tag.

The release also includes:

- deterministic locale-to-base-language-to-English fallback;
- Chinese script/region handling for Android and Apple locale identifiers;
- locale-aware Python, Swift, and Kotlin name/search APIs;
- bundled resource parity and localization CI contracts;
- a `translations.tar.gz` provenance/catalog asset in the GitHub release.

See [the multilingual plan](../MULTILINGUAL-EXERCISE-NAMES-PLAN.md) for source,
review, research-identity, Swift/iPhone, and Kotlin/Android policies.
