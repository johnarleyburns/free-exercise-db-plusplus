# Free Exercise DB++ v1.18.1

Released 2026-11-02.

This compatible patch release promotes the locale-aware v1.18 catalog and
consumer APIs, while preserving stable canonical English exercise IDs and all
released schemas. It also includes CI toolchain hardening for the Kotlin
consumer package and reliable Swift test-fixture discovery in hosted builds.

The catalog covers 927 records for each supported locale. Localized names keep
their explicit source and review status: provisional entries are not presented
as authoritative native terminology, and accepted international English terms
remain explicitly identified. Consumers can use the deterministic
locale-to-base-language-to-English fallback behavior documented in the project.

No required DB++ consumer fields were removed or renamed. This release is
compatible with the v1.x public database, Python, Swift, Kotlin, and R
consumer contracts.
