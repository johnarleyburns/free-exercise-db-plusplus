# Free Exercise DB++ v1.18.2

Released 2026-11-02.

This compatible patch release makes Garmin FIT binary ACTUAL interchange a
tested consumer feature. Python exposes binary FIT import/export through the
optional `fit` dependency extra and the `fedbpp import|export garmin-fit
--binary` CLI commands. Swift exposes `FreeExerciseDBPlusPlusFIT` alongside
the core package.

Exports write standard Activity, Session, Lap, Event, File ID, and Device Info
messages. They also preserve the complete canonical DB++ ACTUAL in chunked
UTF-8 FIT developer fields. This sidecar is required for a lossless import:
strict import rejects FIT files without it instead of guessing at a workout.

The release adds Garmin SDK binary round-trip coverage in Python and Swift,
including command-line operation, invalid input rejection, and the strict
native-only failure mode. No DB++ schema or existing public consumer field was
removed or renamed.
