# Free Exercise DB++ v1.3.0

v1.3 adds strict-by-default, deterministic workout conversion and the `fedbpp`
CLI. FHIR R4 Bundle import/export is operational for the reviewed exact identity
subset and preserves unknown exercises as custom ACTUAL observations in lossy
mode. Garmin FIT mappings remain available, but binary FIT support is not claimed:
the public SDK is not vendored and no mandatory proprietary dependency was added.

See [import/export](../interop/IMPORT-EXPORT.md) and [CLI](../interop/CLI.md) for
the support matrix, reports, provenance, and platform limitations.
