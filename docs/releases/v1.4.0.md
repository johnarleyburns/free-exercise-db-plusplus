# Free Exercise DB++ v1.4.0

v1.4 adds longitudinal analysis derived from existing PLAN revisions, ACTUAL
sessions, optional TARGET profiles, explicit analysis periods, and DB++:

- arbitrary calendar-week, rolling-seven-day, native plan-cycle, phase, and
  custom-range reports;
- deterministic plan revision activation and explicit unresolved linkage;
- canonical PLAN-vs-ACTUAL matching over many sessions;
- missed planned sessions, unplanned work, substitutions, target states,
  exposure frequency, range preservation, and coverage completeness;
- opaque-subject cohort analysis with deterministic muscle-period, session, and
  exercise CSV tables;
- Python public API and `fedbpp analyze-history` / `fedbpp research-export` CLI
  commands.

The release is descriptive. It does not perform inferential statistics or make
causal, hypertrophy, fatigue, injury, or program recommendations.
