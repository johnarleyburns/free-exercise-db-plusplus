the canonical v1.1 PLAN-vs-ACTUAL matcher or starting v1.5 exercise-family work.

- revision activation windows clip scheduled work using half-open boundaries;
- missed session set ranges and canonical exercise adherence are preserved;
- unplanned/unmapped coverage and session-based exposure are complete;
- phase, rolling-window, timezone, calendar, target-transition, and overlap
  semantics are explicit and covered by regression tests.
