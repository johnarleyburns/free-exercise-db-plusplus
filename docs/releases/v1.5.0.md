# Free Exercise DB++ v1.5.0

This release adds the optional exercise-family and relationship enrichment
layer. It publishes `exercise-relationships.json` and its independent
`0.1.0` schema, deterministic build/validation/report tooling, a packaged
Python registry and CLI queries, descriptive DB++ coverage comparison, and
optional PLAN/PLAN and PLAN/ACTUAL relationship context.

The reviewed release contains 16 families and 286 accepted assignments; 587
exercises remain intentionally unassigned. Golden fixtures cover bench press,
squat, deadlift, row, pull-up, chin-up, shoulder press, biceps curl, and
triceps extension decisions. The Garmin audit preserves sixteen exact mappings
and publishes zero unverified family mappings.

Family membership is taxonomic and descriptive. It does not imply physiological
equivalence or recommend substitutions. Existing stable schemas and explicit
substitution semantics are unchanged.
