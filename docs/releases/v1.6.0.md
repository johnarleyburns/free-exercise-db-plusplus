# Free Exercise DB++ v1.6.0

v1.6 adds portable TrainingProfile context and deterministic PlanEvaluation.
The Python package and `fedbpp` CLI support profile validation and evaluation
of existing PLAN artifacts against profile constraints, TARGET requirements,
and optional exercise-family relationships.

This release does not generate plans, recommend exercises, derive training
state, or implement progression/adaptive coaching.

Release preparation: v1.6.0 artifacts and checksums are produced by the
release workflow from this human release commit.
