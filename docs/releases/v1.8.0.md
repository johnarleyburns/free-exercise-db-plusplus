# Free Exercise DB++ v1.8.0

v1.8 adds deterministic PLAN proposal generation to the Python reference
package. `full-body-general-v1` is the initial versioned construction policy.
Generated drafts are schema-validated and always carry the unchanged result of
the canonical PlanEvaluation engine. They do not assign, activate, mutate, or
adapt a PLAN.

This release adds no portable schema: PlanningPolicy and generation requests
are code-level API models, while canonical PLAN remains the output artifact.
