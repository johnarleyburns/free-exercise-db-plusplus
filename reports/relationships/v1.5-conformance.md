# v1.5 roadmap conformance audit

Audit date: 2026-08-25

| Roadmap area | Result |
|---|---|
| Stable v1.0-v1.4.1 contracts | Preserved; the main database and PLAN/ACTUAL/TARGET schemas remain independent of relationships. |
| Architecture | Canonical separate artifact; ADR 0011 rejects a duplicate embedded `familyId` source of truth. |
| Artifact/schema | `exercise-relationships.json`, strict Draft 2020-12 schema, independent schema version 0.1.0. |
| Family identifiers | Stable snake-case IDs, names, reviewed aliases, flat hierarchy. |
| Vocabulary | Small descriptive membership/variation vocabulary; no equivalence or substitution relation. |
| Dimensions | Equipment, grip, stance, angle, laterality, body/load position, assistance, resistance type. Tempo is omitted because the source data cannot support it reliably. |
| Generation | Deterministic reviewed metadata rules, explicit overrides/exclusions, candidate audit, no runtime fuzzy matching. |
| Confidence/provenance | Accepted assignments use high/medium only and carry rule/manual-review taxonomy provenance. |
| Golden review | Full membership snapshots for bench, squat, deadlift, row, pull-up, chin-up, shoulder press, curl, and triceps extension. |
| Validation | Schema strictness, IDs, family references, vocabulary, confidence, duplicate/contradictory assignment, self-edge, ordering, provenance, and canonical equipment checks. No hierarchy means hierarchy cycles are impossible. |
| Reports | Summary, unassigned, family sizes, medium confidence, review/ambiguous candidates, overrides, and category/movement/equipment coverage. |
| Python API | O(1) family/member indexes; family, members, related candidates, aliases/search, dimensions, structural comparison, and one-set coverage differences. |
| PLAN | Optional family set ranges, session exposures, variants, and PLAN-vs-PLAN family/variant differences. Existing muscle analysis is unchanged. |
| ACTUAL | Explicit substitutions remain authoritative and may be enriched with planned/actual family, typed relation, dimensions, and coverage differences. |
| Longitudinal | Stable v1.4 exports are unchanged. Family fields remain optional through relationship/PLAN-ACTUAL helpers rather than destabilizing CSV schemas. |
| Interop | Independent family-target mapping schema and registry. Exact mappings remain exact. The Garmin audit found 16 exact and zero verified broad family mappings. |
| Swift/Kotlin/R | Artifact decoding plus family/member lookup; no claim of full analysis parity. |
| CLI/package | Family, members, related, compare exercises, optional PLAN relationship input, JSON output, embedded wheel artifact, isolated-wheel tests. |
| CI/release | Deterministic rebuild, semantic/schema/golden/API/interop tests, package/language tests, checksums, and idempotent release create/update. |

Intentionally deferred: automatic recommendations, best-substitute ranking,
physiological equivalence, magic similarity scores, difficulty/fatigue/injury
ratings, fine-grained anatomy, embeddings, hierarchy/ontology expansion, and
all v2.0 anatomy work.
